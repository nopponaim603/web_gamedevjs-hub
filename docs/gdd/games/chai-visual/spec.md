## 1. Executive Summary & Concept

### 1.1 Elevator Pitch
ซิมูเลชันเพื่อการศึกษาสำหรับวิทยาการคอมพิวเตอร์ (Computer Science & DSA Interactive Visualizer) ที่ช่วยให้ผู้เรียนเข้าใจอัลกอริทึม โครงสร้างข้อมูล และสถาปัตยกรรมระบบ ด้วยการเห็นการเคลื่อนที่ของข้อมูลทีละสเต็ป (Step-by-step playback) พร้อมสลับดูความซับซ้อนของแต่ละแนวทาง (Approach Leap) และสารบัญหลักสูตรครบ 6 หมวดหมู่

### 1.2 Core Pillars
1. **Interactive Step-by-Step Playhead:** ควบคุมการเล่นย้อนกลับ, เดินหน้าทีละก้าว, ปรับความเร็ว หรือเล่นอัตโนมัติ พร้อมคำอธิบายลอจิกทุกจังหวะ
2. **Multi-Approach Leap:** เปรียบเทียบความซับซ้อนระหว่าง Brute Force $O(n^2)$, Two Pointers $O(n)$, และ Hash Map $O(n)$ แบบเรียลไทม์ พร้อมมิเตอร์นับ Operations
3. **Paper & Ink Hand-Drawn Theme:** งานออกแบบสไตล์สมุดโน้ตสเก็ตช์ กรอบลายมือวาด (Sketch Border) และฟอนต์ลายมือ Patrick Hand & Caveat
4. **Comprehensive 6-Track Curriculum:** สารบัญรวม 6 หมวดหมู่วิชา (DSA, LLD, Networking, OS, DBMS, และ Aptitude Mocks)

## 2. Interactive Features Guide

| ฟังก์ชัน (Feature) | คำอธิบาย (Description) |
| :--- | :--- |
| **Two Pointers Animation** | จำลองการค้นหาคู่บวกเท่ากับ Target (Target: 14) บนอาร์เรย์เรียงลำดับ ด้วยหมุดชี้ L (ส้ม) และ R (ฟ้า) |
| **Approach Switcher** | คลิกสลับดู Time & Space Complexity ของอัลกอริทึมต่างๆ พร้อมหลอดวัดภาระการประมวลผล (Workload Gauge) |
| **Step-by-Step Controls** | ปุ่ม Step Back, Play/Pause, Step Next และ Reset |
| **Theme Toggle** | สลับโหมด Dark Paper (`#111a17`) และ Light Paper (`#f8faf9`) ได้ทันที |
