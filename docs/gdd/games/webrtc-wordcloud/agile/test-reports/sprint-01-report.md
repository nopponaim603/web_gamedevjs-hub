## 4. Key Functional Highlights

### 4.1 P2P Networking
The mesh network successfully synchronized state between the Host and multiple Participants. 
- **Message Latency:** < 50ms (Local simulation).
- **State Recovery:** New participants successfully receive the current word list and topic upon joining (`STATE_SYNC`).

### 4.2 Visualization
The D3.js force-directed graph manages word collisions and scaling based on frequency.
- **Top Words:** Correctly tracked and displayed in the sidebar.
- **Interaction:** Floating words provide immediate visual feedback upon submission.

### 4.3 Quiz Engine
The `QuizManager` successfully parses markdown formatted as:
```markdown
## What is WebRTC?
- [ ] A database
- [x] P2P communication
```
It handles the full lifecycle: `LOBBY` → `COUNTDOWN` → `QUESTION` → `RESULT` → `FINAL`.
