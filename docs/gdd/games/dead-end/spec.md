## 1. Executive Summary & Concept

### 1.1 Elevator Pitch
เกมเอาชีวิตรอดมุมมองด้านบน (Top-down Survival Shooter) ในย่านชานเมืองยามค่ำคืนที่ถูกซอมบี้ยึดครอง ผู้เล่นต้องตั้งรับการบุก 5 ระลอก (5 Waves), ค้นหากล่องเสบียงกระสุน, อัปเกรดความสามารถแบบ Roguelike และเอาชีวิตรอดจนกว่าเฮลิคอปเตอร์อพยพจะมาถึง!

### 1.2 Core Pillars
1. **5-Wave Survival Loop:** ตั้งรับฝูงซอมบี้ที่ทวีความดุร้ายขึ้นเรื่อยๆ จนถึงบอสประจำเซกเตอร์ (Sector Threat Boss)
2. **Dual-Weapon Arsenal & Tactical Movement:** ปืนกล M4 Carbine (Full-Auto) และ Shotgun (Spread Damage), พร้อมระบบ Sprint (Shift) และ Dodge Roll (Space)
3. **Roguelike Field Perks:** สุ่มเลือกอัปเกรด 1 ใน 3 หลังจบแต่ละเวฟ (Hollow Point, Fast Hands, Sprint Booster, Heavy Barrel)
4. **Radar Minimap & Dynamic Night Ambience:** มีเรดาร์ระบุตำแหน่งศัตรู/กล่องเสบียง และเสียงบรรยากาศความมืดสุดกดดัน

## 2. Controls & Interaction Guide

| การกระทำ (Action) | คีย์บอร์ด & เมาส์ (Desktop) | จอยเกม / ทัชสกรีน (Mobile) |
| :--- | :---: | :---: |
| **เคลื่อนที่ (Move)** | `W` / `A` / `S` / `D` | Virtual Left Joystick |
| **เล็งทิศทาง (Aim)** | เมาส์ (Mouse 360°) | Virtual Right Aim Pad |
| **ยิงปืน (Fire)** | คลิกซ้าย (Left Click) | ปุ่ม Fire Button |
| **วิ่งเร็ว (Sprint)** | `Shift` (ใช้ Stamina) | ปุ่ม Sprint |
| **กลิ้งหลบ (Dodge Roll)** | `Space` | ปัดนิ้วสองครั้ง (Double Tap) |
| **รีโหลดกระสุน (Reload)** | `R` | แตะที่แถบกระสุน |
| **สลับอาวุธ (Switch Weapon)** | `Q` หรือ `1` / `2` หรือ Scroll Wheel | แตะไอคอนปืน |
