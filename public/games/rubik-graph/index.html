Planar Cube ⇄ 3D Cube · ผังระนาบเชื่อมโยงสถานะ

| |

ผังระนาบวงกลมตัดกันทางซ้าย และรูบิค 3 มิติทางขวา คือสถานะเดียวกันแบบ Equivalence
เมื่อหมุนฝั่งใดฝั่งหนึ่ง (ปุ่ม 3D หรือปุ่ม ↺ ↻ บนผัง 2D) ทั้งสองฝั่งจะหมุนเชื่อมโยงพร้อมกัน

ผังระนาบวงกลมตัดกัน (Planar View)

วงกลมซ้อน 3 ชุดตัดกันสองต่อสอง → 54 จุดตัด = 54 สติ๊กเกอร์; คลิก ↺ / ↻ หรือคลิกที่กลุ่มสีเพื่อหมุนตามทิศทาง

รูบิค 3 มิติ (3D Cube)

ลากเมาส์เพื่อหมุนมุมมอง 3 มิติ
คีย์ลัดบนแป้นพิมพ์: Y / W / G / B / R / O , Shift+ตัวอักษร = หมุนทวนเข็ม
การคำนวณ Rubik Group บนเว็บบราวเซอร์ 100% เชื่อมโยงสเตทระหว่าง 2D และ 3D อย่างสมบูรณ์
